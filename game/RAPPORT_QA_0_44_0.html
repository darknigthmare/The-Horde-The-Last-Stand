Lecture des quatre testeurs

  • QA1 — Fonctionnel/chaos : huit familles jouables, enchaînements tir/recharge/grenade/priorité, économie et états numériques.
  • QA2 — UX/navigation : menu, sous-menus, camp, À propos, tiroirs, Échap, focus et densité d'information.
  • QA3 — Combat/spatial : 45 armes, quatre vues, contrechamp, mains/armes, projectiles, alliés, Armurier et stabilité balistique.
  • QA4 — Extrêmes : sauvegardes, profils incompatibles, production sans API de test, 1920×1080, 1280×720, 896×414 et 414×896.

Limites documentées

  • Les très anciennes suites monolithiques Atelier/Montage et Protocoles ont été explorées mais ne sont pas comptées lorsqu’elles dépassent la fenêtre d’exécution avant leur fin.
  • Le dernier segment production des protocoles a été isolé puis validé 4/4 sans API développeur.
  • La correction finale de Situation du poste est CSS uniquement; QA ×4, régression et syntaxe ont été rejouées après reconstruction.
