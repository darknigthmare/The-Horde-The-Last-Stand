# Reprendre depuis la 0.40.6

Exporter le profil JSON depuis la version précédente et conserver cette copie. Ouvrir le nouveau HTML, puis Options → Sauvegardes → Importer. Contrôler les préparations proposées dans Reprendre avant de repartir.

Le schéma est toujours 12. Les six presets, pièces et conversions ne sont ni recréés ni réinitialisés. Le devis et la fiche du poste sont temporaires et ne sont pas sérialisés. Les stocks des campagnes restent indépendants. Aucune des anciennes versions 0.41 annoncées ou manquantes n'est nécessaire.

En cas d'alerte du navigateur sur le stockage local, utiliser régulièrement Exporter le profil. Cette reprise ne prétend pas offrir de sauvegarde cloud. Garder le HTML/ZIP et les JSON sur votre machine reste recommandé.

Ne pas ouvrir l'HTML à l'intérieur de l'archive : extraire le ZIP puis lancer `JOUER_DERNIERE_LIGNE.html`.
