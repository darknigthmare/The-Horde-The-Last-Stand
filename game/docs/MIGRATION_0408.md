# Reprendre une partie dans la 0.40.8

Exporter le profil JSON de la 0.40.7 (ou de la version précédente), conserver le JSON et l’ancien HTML. Ouvrir le nouveau jeu, puis Options → Sauvegardes → Importer. Vérifier les préparations proposées dans Reprendre.

Le schéma reste 12. Cette passe ne rajoute aucun paramètre persistant ni achat. Elle ne réinitialise ni presets, ni montages, ni armes, ni stocks. Les métadonnées graphiques de lancement restent temporaires, propres aux projectiles de la vague.

Pour jouer depuis le ZIP, extraire le dossier puis ouvrir JOUER_DERNIERE_LIGNE.html. Aucun Node, Python ou serveur n’est nécessaire pour jouer. Ils ne sont utiles que pour reconstruire et exécuter les tests. Sauvegarder régulièrement un export JSON si le navigateur avertit que le stockage local est indisponible. Aucune version 0.41 manquante n’est requise.
