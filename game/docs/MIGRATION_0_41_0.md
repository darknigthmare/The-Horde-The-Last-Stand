# Migration vers 0.41.0

La 0.41.0 ne change pas le schéma de sauvegarde (**12**). Les profils 0.40.8, 0.40.9 et 0.40.10 peuvent être chargés directement.

Les changements concernent la présentation spatiale et le raccord entre rendu et effets de combat. Ils ne nécessitent ni conversion manuelle, ni nouvelle campagne, ni réattribution des équipements.

Pour une copie autonome : conserver tout le dossier et lancer `JOUER_DERNIERE_LIGNE.html`. Pour reconstruire la build depuis les sources : exécuter `node build.mjs`.
