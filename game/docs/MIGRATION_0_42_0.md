# Migration vers 0.42.0

Aucune migration de sauvegarde n’est nécessaire.

- schéma de sauvegarde : **12**, inchangé ;
- les données de campagne, arsenal, doctrines, presets, secteurs et progression continuent d’utiliser les structures précédentes ;
- la nouvelle couche UI est installée à l’exécution et n’écrit aucune nouvelle donnée de gameplay obligatoire ;
- le plein écran et le type d’entrée détecté sont des états de présentation uniquement.

Pour repartir de la 0.41.0, remplacer le dossier du jeu par la 0.42.0 puis ouvrir `JOUER_DERNIERE_LIGNE.html`. Les sauvegardes du navigateur restent utilisables.
